# Phase 5A WIZ850io Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Capture only the WIZ850io Ethernet module interface and verify its connectivity to the frozen ESP32-S3 GPIO nets.

**Architecture:** Add a dedicated hierarchical sheet using one custom 12-pin module symbol visually divided into official J1 and J2 1x6 headers. Connect it through global power and frozen Ethernet nets; retain existing MCU-side reset/select biases and add only carrier-side supply bypassing justified by the vendor module schematic.

**Tech Stack:** KiCad 9 schematic format, KiCad MCP, official WIZnet WIZ850io documentation and revision 1.1 schematic.

## Global Constraints

- Do not modify Phase 3 or Phase 4B electrical topology.
- Do not capture RS485, DI, DO, sensors, USB-C, or PCB layout.
- Do not guess module footprint geometry.
- Do not suppress ERC warnings without electrical justification.
